Неупорядоченные списки

Начальный тег: обязателен

Конечный тег: не обязателен

Определения атрибутов:

  1. type — Нежелателен. Этот атрибут устанавливает стиль элемента списка. Возможные значения:
    • disc — закрашенный круг
    • square — черный квадрат
    • circle — окружность
  2. compact — Нежелателен. Если этот логический атрибут установлен, он сообщает браузерам о том, что генерировать список нужно более компактно.
    • Один атрибут
    • Второй атрибут

Примеры неупорядоченных списков:

  • Список с type="disc"
  • Второй элемент
  • Список с type="circle"
  • Еще элемент
  • Список с type="square"
  • И еще один
  • Компактный список (атрибут compact)
  • Второй элемент
